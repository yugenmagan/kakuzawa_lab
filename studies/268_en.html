Elfen Lied Mean Time

Wayback Machine · Japanese original

I'm thinking of launching an ambitious project (?) called the Great Elfen Lied Encyclopedia (provisional title), although nothing concrete has been done yet. For its time notation, I considered a format called “Elfen Lied Mean Time,” defined as follows. Elfen Lied Mean Time (EMT): the number of milliseconds elapsed since 00:00:00 on June 6, 2002, Japan Standard Time (GMT+09:00), the release date of Young Jump 2002 No. 27 containing the first serialized chapter of Elfen Lied. In JavaScript, it would look like this: var emt; var now = new Date(); var est = new Date(2002,6,6); // Since this is a difference, ignore the discrepancy with JST. emt = now.getTime() - est.getTime(); The resulting value of emt is in milliseconds. (Not tested.) The idea is so silly that I've rejected it. February 28, 2003.
