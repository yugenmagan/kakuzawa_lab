Стандартное время

РусскийEnglish日本語

Сейчас я подумываю запустить один амбициозный проект (?) под названием «Большая энциклопедия „Эльфийской песни“ (рабочее название)» (пока, правда, ничего конкретного не сделано). Для обозначения времени в ней я придумал формат «Стандартное время „Эльфийской песни“» и определил его следующим образом.

Стандартное время «Эльфийской песни» (EMT): число миллисекунд, прошедших с 00:00:00 6 июня 2002 года по японскому стандартному времени (GMT+09:00), когда вышел номер Young Jump № 27 за 2002 год с первой главой «Эльфийской песни».

На JavaScript это выглядело бы так:

var emt;

var now = new Date();

var est = new Date(2002,6,6);

// Поскольку берём разность, погрешностью относительно JST пренебрегаем.

emt = now.getTime() - est.getTime();

Полученное значение переменной emt измеряется в миллисекундах. (Не проверял.)

Идея настолько дурацкая, что отклонена.

28 февраля 2003 года.
